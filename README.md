# Sathena Planner

Weekrooster, verlofaanvragen, dagplanning en bus-toewijzing voor Sathena.

- `index.html` – de complete app (één bestand)
- `config.js` – Supabase-koppeling (URL + anon key)
- `supabase-schema.sql` – tabel en realtime-instellingen voor Supabase

Zonder ingevulde `config.js` werkt de app alleen lokaal in de browser.
